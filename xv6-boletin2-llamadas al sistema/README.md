# xv6 - Boletín 2: Llamadas al Sistema

Esta carpeta implementa los ejercicios de llamadas al sistema (`date`, `dup2`, `exit` y `wait`).

Para que compile y funcione correctamente, se ha silenciado temporalmente el código a medias del resto de ejercicios hechos en clase (en concreto, `case T_PGFLT:` en `trap.c` y la asignación perezosa en `sys_sbrk()` dentro de `sysproc.c`).
